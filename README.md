# StyleCart – Fashion E-commerce Website

StyleCart is a modern, responsive fashion e-commerce frontend
built using React, TypeScript, Vite and Tailwind CSS.

## Features

- Responsive fashion storefront
- Product listing and product details
- Product search, filtering and sorting
- Shopping cart functionality
- Wishlist functionality
- Checkout form and order summary
- Order confirmation
- Order history
- LocalStorage persistence
- Responsive mobile navigation

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- React Router DOM
- Context API
- Lucide React
- React Hot Toast
- LocalStorage

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

npm install

Start development server:

npm run dev

Create production build:

npm run build

## Note

This is a frontend-only demonstration project.
Payments, authentication and backend order processing
are not integrated.
